#Final Reflection

The project was hard from the start, because we had to repeat many of the missions again and again. The most difficult part for us to do was typing the commands and then waiting for them to load, since sometimes it took so long that we weren't sure if it was working. Setting up the WordPress site was also a bit hard. What helped us was learning from our mistakes, doing the steps again until they worked, and being patient while things loaded. 
In the end, we built a working website, running on a virtual server inside our laptop. The site keeps its data even after the server restarts, it backs itself up, and only the ports we really need are open. Everything is also written down so someone else can repeat it. 
What we learned is that a website is more than the page people see, because the database, the backups, and the security behind it matter just as much. We also learned that mistakes are part of the process, and that writing the steps down clearly makes the work easier to repeat. If we built it again, We would try to do it without mistakes, and I think we would finish faster because we now know what each step is for.
