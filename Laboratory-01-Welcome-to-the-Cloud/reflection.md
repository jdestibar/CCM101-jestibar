# Reflection

This laboratory activity helped me understand the basics of working in a cloud-based Linux environment using KillerCoda. I learned how to create and manage a Linux user, use basic Linux commands, and check important system information such as the Linux distribution, kernel version, CPU, memory, and disk space.

I also learned how to create and organize folders and Markdown files using the Linux terminal. Creating `system-information.md` and `about-me.md` helped me practice documenting my work in an organized way. In addition, creating a GitHub repository taught me how to keep my laboratory activities, screenshots, and documentation in one place.

Overall, this activity gave me a better understanding of how Linux, cloud environments, Markdown, and GitHub can be used together. It also helped me become more comfortable using the terminal and documenting technical work. I believe the skills I learned from this activity will be useful for the next Cloud Computing laboratory activities.
