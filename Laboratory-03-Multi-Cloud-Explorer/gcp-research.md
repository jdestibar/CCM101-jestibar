# Google Cloud Platform (GCP) Research

## Brief Overview
Google Cloud Platform (GCP) is Google's public cloud offering, with its earliest services (App Engine) launching in 2008. GCP runs on the same infrastructure that powers Google Search, YouTube, and Gmail. It has built a strong reputation in data analytics, artificial intelligence/machine learning, and Kubernetes, since Google originally created Kubernetes for its own internal use.

## Global Infrastructure
GCP infrastructure is organized into **Regions** and **Zones**, connected by Google's own private global fiber network rather than the public internet, which improves speed and reliability between locations. GCP currently operates in around 40 regions worldwide.

## Cloud Management Console
The **Google Cloud Console** is the web-based interface for managing GCP resources, viewing billing, and monitoring performance. It includes Cloud Shell, a free browser-based terminal preloaded with common developer tools, and integrates tightly with Google Workspace.

## Four (4) Core Services
1. **Compute Engine** – Customizable virtual machines for running workloads.
2. **Cloud Storage** – Scalable object storage for unstructured data.
3. **Virtual Private Cloud (VPC)** – Global, software-defined networking for GCP resources.
4. **Identity and Access Management (Cloud IAM)** – Manages permissions and access control across GCP resources.

## Three (3) Advantages
1. **Leader in AI/ML and data analytics** – Services like Vertex AI, BigQuery, and TPUs (Tensor Processing Units) give GCP an edge for AI-heavy and data-heavy workloads.
2. **Best-in-class Kubernetes support** – Since Google created Kubernetes, GKE (Google Kubernetes Engine) is widely considered the most mature managed Kubernetes offering.
3. **High-performance global network** – Google's private backbone network reduces latency and improves reliability compared to relying on the public internet.

## Typical Enterprise Use Cases
- Big data analytics and business intelligence with BigQuery
- Training and deploying machine learning models
- Running containerized applications with Kubernetes at scale
- Real-time data processing and streaming pipelines
- Startups and tech companies needing modern, developer-friendly tooling
