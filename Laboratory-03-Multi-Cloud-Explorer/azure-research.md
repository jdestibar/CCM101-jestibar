# Microsoft Azure Research

## Brief Overview
Microsoft Azure is Microsoft's public cloud platform, launched in 2010. Azure is especially popular among enterprises that already rely on Microsoft products such as Windows Server, Active Directory, and Microsoft 365, since it integrates tightly with these existing tools. It is currently the second-largest cloud provider by market share, right behind AWS.

## Global Infrastructure
Azure's infrastructure is built around **Regions** grouped into **Geographies**, with each region containing one or more datacenters. Azure operates in over 60 announced regions worldwide, more than any other major cloud provider, which helps organizations meet local data residency and compliance requirements.

## Cloud Management Console
The **Azure Portal** is Azure's web-based management console, used to create, configure, and monitor resources. It also offers Azure Cloud Shell for command-line management and Azure Resource Manager (ARM) templates for infrastructure as code.

## Four (4) Core Services
1. **Azure Virtual Machines** – On-demand, scalable virtual servers.
2. **Azure Blob Storage** – Object storage for unstructured data such as documents, images, and backups.
3. **Azure Virtual Network (VNet)** – Provides isolated and secure networking for Azure resources.
4. **Microsoft Entra ID (formerly Azure Active Directory)** – Identity and access management service for authentication and single sign-on.

## Three (3) Advantages
1. **Best-in-class Microsoft integration** – Seamlessly connects with Windows Server, Active Directory, Microsoft 365, and Office apps.
2. **Strong hybrid cloud support** – Azure Arc and Azure Stack make it easy for organizations to run workloads across on-premises and cloud environments.
3. **Wide global presence** – With the most regions of any provider, Azure helps businesses meet data sovereignty and compliance needs.

## Typical Enterprise Use Cases
- Migrating on-premises Windows Server and Active Directory environments to the cloud
- Hosting Microsoft 365-integrated business applications
- Hybrid cloud deployments for organizations not fully moving off-premises
- Enterprise identity and access management
- Business intelligence and reporting with Power BI integration
