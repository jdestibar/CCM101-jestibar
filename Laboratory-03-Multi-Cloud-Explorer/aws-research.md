# Amazon Web Services (AWS) Research

## Brief Overview
Amazon Web Services (AWS) is the cloud computing arm of Amazon, launched in 2006. It is the largest and most widely adopted public cloud provider in the world, offering over 200 fully featured services from data centers across the globe. AWS pioneered the pay-as-you-go cloud model and is used by everyone from startups to Fortune 500 companies and government agencies.

## Global Infrastructure
AWS infrastructure is organized into **Regions** (separate geographic areas) and **Availability Zones** (isolated data centers within a region). As of 2025, AWS operates in over 30 launched regions and 100+ Availability Zones worldwide, with additional regions planned. AWS also has a global network of Edge Locations used for content delivery through Amazon CloudFront.

## Cloud Management Console
The **AWS Management Console** is a web-based interface that lets users manage all AWS services in one place — creating resources, monitoring usage, setting up billing alerts, and managing security through IAM. It also includes AWS CloudShell, a browser-based command-line tool for interacting with AWS resources directly.

## Four (4) Core Services
1. **Amazon EC2 (Elastic Compute Cloud)** – Resizable virtual servers for running applications.
2. **Amazon S3 (Simple Storage Service)** – Scalable object storage for files, backups, and static websites.
3. **Amazon VPC (Virtual Private Cloud)** – Lets users create isolated, customizable network environments in the cloud.
4. **AWS IAM (Identity and Access Management)** – Controls who can access AWS resources and what actions they can perform.

## Three (3) Advantages
1. **Widest range of services** – AWS offers the largest service catalog of any provider, covering compute, storage, databases, AI/ML, IoT, and more.
2. **Mature and reliable infrastructure** – Being the first major cloud provider, AWS has the most battle-tested global infrastructure and the largest community support base.
3. **Strong scalability and flexibility** – Auto Scaling and a pay-as-you-go pricing model let businesses grow their infrastructure without large upfront investment.

## Typical Enterprise Use Cases
- Hosting scalable web and mobile applications
- Big data processing and analytics
- Disaster recovery and backup solutions
- Machine learning model training and deployment
- E-commerce platforms requiring high availability and global reach
